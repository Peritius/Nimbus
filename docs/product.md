# Продукт: трей, панель прогноза, настройки

## Трей

Иконка — текущая температура числом на полупрозрачном тёмном фоне, плюс знак
(`+18`, `-3`, `0`). Пока данных нет — прочерк, а не выдуманное число. Размер
текста задаётся масштабом 1–100 % в настройках и применяется на лету.

Меню: **7-day Forecast**, **Settings…**, **About**, **Quit**. Пункта «Обновить»
нет: обновление идёт по таймеру с интервалом из конфига, а при открытии панели
используется кэш, если он не старше интервала.

Тултип: температура, ощущается, влажность, ветер, давление, текстовое состояние
погоды. Язык — из настроек.

## Панель прогноза

Обычное окно с рамкой WM (не поповер без рамки): закрывается только своей
кнопкой или повторным кликом по иконке трея. Escape и потеря фокуса её не
закрывают.

Содержимое — таблица из пяти колонок: день, символ, макс, мин, осадки/ветер;
строка заголовков, линейка, семь строк с тонкими разделителями. Без карточек и
без сводного заголовка — такой вид пробовали и откатили.

Поведение окна:

- не показывается в списке задач и на пейджере, всегда поверх окон;
- в GTK — sticky на всех рабочих столах; в Qt этого нет (ограничение);
- перетаскивается за любую часть тела;
- позиция запоминается, если панель реально сдвинули, и восстанавливается при
  следующем открытии; иначе — угол рабочей области, ближайший к курсору;
- на Wayland позиция не запоминается (клиент не знает координат окна);
- данные обновляются на месте, без пересоздания окна (в Qt это пока не так —
  см. `todo.md`, шаг 3).

## Настройки

Одно окно, поля по порядку:

| Поле | Значения |
|---|---|
| Город | текстовое поле + кнопка поиска, список результатов, выбор строки |
| Широта, долгота | текст, проверяется `config.ParseCoord`; мусор не затирает прежнее значение |
| Единицы температуры | °C / °F |
| Давление | гПа / мм рт. ст. / inHg |
| Ветер | м/с / км/ч |
| Тема окон | авто / тёмная / светлая |
| Язык | English / Українська |
| Масштаб шрифта | слайдер 1–100 %, превью иконки трея на лету |
| Интервал обновления | 5 / 30 / 60 / 720 / 1440 минут |

Кнопки: сохранить, отмена, сброс к умолчанию. Отмена и закрытие окна крестиком
возвращают «ничего не менять», а не половину правок.

Тема действует на все окна: панель, настройки, About, диалог ошибки. На Qt
младше 6.8 опция присутствует, но окна идут за системной темой.

## About

Название, версия, дата сборки, краткое описание, логотип (GTK и Windows;
в Qt пока только текст), кнопка OK.

## Ошибки

Сетевая ошибка и прочие сбои показываются диалогом с заголовком приложения.
Диалог не модальный и не блокирует трей; одновременно — не больше одного.

## Данные и обновление

Источник — Open-Meteo, без ключа и регистрации. Прогноз — 7 дней, текущая
погода отдельным запросом. Кэш привязан к координатам: сменили город — старые
данные не показываются. Если сети нет, панель показывает последний кэш, а трей —
прочерк и текст ошибки в тултипе.

## Локализация

Два языка: английский и украинский. Переключение в настройках, без перезапуска.
Единицы измерения, названия условий погоды, дни недели, тултип, меню и подписи
окон — всё через `internal/i18n`. Числа и даты форматируются под выбранный язык.

## Файлы

Конфиг: `%AppData%\Nimbus\config.json` на Windows, `~/.config/Nimbus/config.json`
на Linux. Лог: рядом с конфигом, потому что GUI-сборка не имеет консоли.
